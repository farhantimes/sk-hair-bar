# SK Hair Bar International Salon & Academy

A responsive frontend for the salon and beauty academy in Jalandhar, Punjab.

## Website

Built with HTML, CSS and vanilla JavaScript. No dependencies or build step are required. Open `index.html` locally or publish the repository root with GitHub Pages.

## Features

- Salon services and current offers
- Academy courses and live seminar information
- Studio photo gallery with an accessible image viewer
- Client and student testimonials
- Appointment, academy, seminar and callback enquiry forms
- Telephone links and directions

Booking forms prepare a message for the visitor to review and send using WhatsApp. Appointments are confirmed by the salon; this frontend does not store or send bookings itself.

## GitHub Pages

Publish from the `main` branch and the `/ (root)` folder under **Settings → Pages**. The `.nojekyll` file serves the website as static files.

The four supplied studio images are in `assets/images/` and retain their original filenames. All website assets use relative paths so the site also works under a GitHub Pages project URL.
